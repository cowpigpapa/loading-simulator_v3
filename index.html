    USER GUIDE

    LoadWise 사용 가이드

    제품 등록부터 3D 적재안 확인과 프로젝트 저장까지 한 화면에서 진행할 수 있습니다.

    STEP 01제품 등록직접 입력하거나 Excel·CSV 파일을 불러옵니다.
    STEP 02조건 선택컨테이너 규격과 적재 최적화 기준을 선택합니다.
    STEP 03결과 확인3D 배치, 적재 순서와 고정재 권고를 검토합니다.
    STEP 04저장·내보내기프로젝트를 저장하거나 Excel 계획을 내려받습니다.
    1. 제품 입력
    • 직접 입력에서는 제품명, 형상, 수량, 길이·너비·높이와 개당 중량을 입력합니다.
    • 여러 제품은 Excel 또는 CSV로 한 번에 등록할 수 있습니다.
    • 눕힘 허용은 높이 축 변경을 허용하며, 상부 적재 금지는 해당 화물 위의 배치를 막습니다.
    2. 컨테이너와 최적화 기준
    • 20ft, 40ft, 40ft High Cube, 45ft High Cube를 지원합니다.
    • 안전 적재는 지지 조건을 보수적으로 적용하고 최대 적재는 적재 수량을 우선합니다.
    • 폭 우선은 긴 방향 사용을 일부 허용하면서 짧은 방향의 잔여 공간을 먼저 줄입니다.
    • 자동 추천은 화물 특성에 따라 안전형 또는 최대적재형을 선택합니다.
    3. 시뮬레이션 결과 확인
    • 3D와 상면 보기로 배치를 확인하고 단계 재생으로 실제 적재 순서를 검토합니다.
    • 여러 컨테이너가 필요하면 화살표로 각 컨테이너 결과를 이동합니다.
    • 각재·부목, 에어백과 래싱 밴드 표시는 화면에서 켜고 끌 수 있습니다.
    4. 프로젝트 저장
    • 비로그인 상태에서는 현재 브라우저에, 로그인 상태에서는 계정별 클라우드에 저장됩니다.
    • 저장 목록에서 프로젝트를 불러오면 저장된 조건으로 시뮬레이션이 자동 실행됩니다.
    • 미배치 화물이 있으면 안전 검토를 위해 Excel 내보내기가 제한됩니다.
    현장 확인 필수결과는 작업 검토용 제안입니다. 실제 상차 전 화물 강도, 중량중심, 운송 조건과 고정재 지침을 확인하세요.

    ALGORITHM POLICY · v1.2

    알고리즘 정책과 한계

    LoadWise의 결과는 작업 검토를 위한 휴리스틱 제안이며 전역 최적해나 안전 인증을 의미하지 않습니다.

    안전형상부 지지 100%바닥 우선·중심 지지·측면 안정성
    최대적재형상부 지지 70% 이상적재 수량 우선·중심 조건 유지
    자동 추천화물 특성 기반안전형과 최대적재형 중 선택
    폭 우선형짧은 방향 우선긴 방향 여유를 허용하고 잔여 폭·내부 틈 최소화
    현재 계산 로직
    1. 입력 데이터를 공통 제품 모델로 정규화합니다.
    2. 허용 회전과 Extreme Point 후보를 생성합니다.
    3. 경계·충돌·중량·상부 금지·바닥 및 중심 지지를 검사합니다.
    4. 낮은 위치 → 안쪽 → 좌측 순서와 공간 점수로 후보를 비교합니다.
    5. 미배치 화물은 다음 컨테이너에서 다시 계산합니다.
    절대 우회하지 않는 안전 조건
    • 컨테이너 경계, 제품 충돌과 최대 중량 준수
    • 상부 적재 금지 화물 위 배치 금지
    • 상부 화물 중심이 실제 지지 영역 안에 존재
    • 원통 위 박스 금지, 원통 적층 정렬 조건 적용
    • 입력 수량 = 적재 수량 + 미배치 수량
    측면 지지와 래싱 기준
    • 각 방향에서 면의 50% 이상 접촉하면 지지로 인정합니다.
    • 높은 세장 화물은 최소 2방향 지지가 필요합니다.
    • 1~2방향 부족은 래싱 밴드를 권고하고, 3방향 이상 부족은 배치하지 않습니다.
    현재 계산하지 않는 한계
    • 제품별 압축강도와 누적 상부 하중
    • 전체 무게중심, 바닥 집중하중과 차량 축하중
    • 마찰·충격·진동, 래싱 용량과 에어백 압력
    • 위험물 격리, 냉동 공기 순환과 법규 적합성
    • 모든 조합을 탐색하는 전역 최적화
    알고리즘 변경 원칙
    • 공통 안전 조건을 우회하지 않습니다.
    • 기존 전략과 같은 입력으로 결과를 비교합니다.
    • 경계·충돌·중량·지지 회귀 테스트를 통과해야 합니다.
    • 미배치와 실패 이유를 숨기지 않고 정책 버전과 변경 이력을 갱신합니다.
    현장 확인 필수실제 상차 전 화물 사양, 컨테이너 상태, 고정재 제조사 지침과 운송 규정을 확인하세요.
