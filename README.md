# LoadWise v3

제품 규격, 중량, 수량과 적재 제약을 입력하면 컨테이너별 배치·적재 순서·고정재 위치를 계산하고 3D로 보여주는 브라우저 기반 컨테이너 로딩 시뮬레이터입니다.

- 현재 단계: Vercel 공개 베타
- v3 서비스: https://loadwise-v3.vercel.app/
- v3 저장소: https://github.com/cowpigpapa/loading-simulator_v3
- 운영 중인 v2: https://cowpigpapa.github.io/loading-simulator_v2/
- 제품 요구사항: [LOADING-SIMULATOR-PRD.md](LOADING-SIMULATOR-PRD.md)
- 상단 `알고리즘 정책` 팝업 및 원문: [ALGORITHM-POLICY.md](ALGORITHM-POLICY.md)

## 주요 기능

- 직접 입력 및 Excel/CSV 업로드
- 박스형·원통형 제품 지원
- 등록 제품 수량 직접 입력 및 화살표 조절
- 눕힘 허용·상부 적재 금지 수정
- 20ft, 40ft, 40ft High Cube, 45ft High Cube 지원
- 안전 적재와 최대 적재 모드
- Extreme Point 및 DBLF 기반 후보 탐색
- 지지율과 중심 지지 검사
- 전·후·좌·우 4방향 측면 지지 및 래싱 필요 방향 판정
- 단일 컨테이너 부족 시 복수 컨테이너 자동 분할
- 안쪽부터 진행되는 단계별 적재 재생
- Three.js 기반 3D·상면 보기
- 문쪽 각재·부목 및 벽면·화물 간 에어백 추천
- 고정재 표시 토글
- 계산 진행률과 완료 시간
- 전체 계획 Excel 내보내기
- 일일·누적 방문자 표시
- 제품 목록과 컨테이너 설정을 프로젝트로 저장·불러오기
- 저장 프로젝트를 불러오면 3D 시뮬레이션 자동 실행
- 이메일 매직 링크 로그인과 계정별 클라우드 저장

## 프로젝트 저장

첫 저장에서 이름을 확인하고, 이후 `저장`은 확인 후 현재 프로젝트를 갱신합니다. `신규 저장`은 현재 작업을 다른 이름의 새 프로젝트로 보존합니다. Excel/CSV 파일명이나 처음 등록한 제품명이 저장 이름으로 자동 제안되며, `저장 목록`에서 기존 프로젝트를 불러오거나 삭제할 수 있습니다. 저장 프로젝트를 불러오면 저장된 제품과 컨테이너 조건으로 시뮬레이션이 즉시 실행됩니다.

- 비로그인: 현재 브라우저 프로필의 `localStorage`에 저장
- 이메일 매직 링크 로그인: Supabase의 사용자 계정별 클라우드 저장
- 상단 계정 버튼은 로그인 상태에 따라 `로그인`과 `로그아웃`으로 전환
- `새 프로젝트`는 제품·설정·시뮬레이션 결과를 초기 상태로 되돌림
- 저장하지 않은 변경사항이 있으면 프로젝트 교체 전에 확인
- 손상된 로컬 데이터는 자동으로 덮어쓰지 않음

로컬 저장은 다른 브라우저나 기기로 동기화되지 않으며 같은 브라우저 프로필을 사용하는 사람과 분리되지 않습니다. 개인별 보안과 여러 기기 연동이 필요하면 로그인해야 합니다. 클라우드 프로젝트는 PostgreSQL RLS 정책으로 로그인 사용자별 접근을 제한합니다.

## 입력 항목

| 항목 | 설명 |
|---|---|
| 제품명·제품군 | 제품 식별 정보 |
| 제품 형상 | 박스형 또는 원통형 |
| 길이·너비·높이 | mm 단위 외형 치수 |
| 개당 중량 | kg 단위 중량 |
| 수량 | 동일 규격 제품 수량 |
| 눕힘 허용 | 높이 축을 바꾸는 회전 허용 여부, 기본값은 미선택 |
| 상부 적재 금지 | 해당 제품 위에 다른 화물을 놓지 않음 |

바닥면에서 길이와 너비를 바꾸는 회전은 항상 평가합니다. `눕힘 허용`은 제품을 옆으로 눕혀 높이 축까지 바꿔도 되는지를 뜻합니다.

## 최적화 모드

### 안전 적재

- 바닥의 빈 공간을 먼저 채웁니다.
- 상부 적재는 바닥면 지지율 100%를 요구합니다.
- 화물 중심이 실제 지지 영역 안에 있어야 합니다.
- 상부 적재 금지 제품과 불안정한 상부 배치를 제외합니다.
- 누적 높이가 바닥면 최소 치수의 1.5배를 넘는 화물은 전·후·좌·우 중 최소 2방향 지지가 있어야 합니다.

### 최대 적재

- 안전 적재 결과에 추가 적재하는 안과 전체 고밀도 배치안을 비교합니다.
- 상부 적재 최소 지지율은 70%이며 중심 지지 조건은 유지합니다.
- 적재 수량을 우선하고 같은 수량이면 더 짧은 깊이를 사용한 결과를 선택합니다.

## 고정재 추천 기준

- 문쪽 노출 화물에는 폭 전체를 받치는 가로 각재와 부목 3~6개를 추천합니다.
- 좌측·우측·안쪽 벽 간극이 100mm 이상이면 바닥부터 에어백을 추천합니다.
- 600mm가 넘는 벽 간극은 600mm 이하의 여러 에어백으로 분할합니다.
- 화물 사이 간극은 120~600mm 범위에서 충돌이 없을 때 에어백을 추천합니다.
- 측면 지지는 각 방향에서 화물 폭 또는 높이의 50% 이상 맞닿을 때 인정합니다.
- 4방향 중 1~2방향이 부족하면 해당 방향에 래싱 밴드를 추천하고, 3방향 이상이 부족하면 배치를 허용하지 않습니다.
- 원통 상부 적재는 바닥 지지와 중심 지지, 최소 2방향 측면 지지를 모두 만족하면 허용합니다.
- 실제 작업 전 컨테이너 바닥 고정 허용 여부와 고정재 제조사 지침을 확인해야 합니다.

## 좌표 체계

- X: 컨테이너 문에서 안쪽
- Y: 컨테이너 좌측에서 우측
- Z: 컨테이너 바닥에서 위

적재 순서는 기본적으로 가장 안쪽부터 문쪽으로, 같은 위치에서는 아래층부터 생성됩니다.

## 실행

정적 웹 애플리케이션이며 로컬 개발 서버와 배포용 빌드를 제공합니다.

```bash
npm test
npm run build
```

주요 파일:

```text
index.html          화면 구조
styles.css          기본 스타일
layout-fixes.css    반응형 레이아웃 보정
app.js              입력, 적재 알고리즘, 3D, 내보내기
project-model.js    저장 데이터 정규화
project-store.js    로컬·Supabase 저장과 로그인
supabase-schema.sql 사용자별 저장 테이블과 RLS 정책
vendor/three.min.js 로컬 3D 엔진
LOADING-SIMULATOR-PRD.md 제품 요구사항 문서
ALGORITHM-POLICY.md 알고리즘 원칙·판정 기준·한계 문서
```
